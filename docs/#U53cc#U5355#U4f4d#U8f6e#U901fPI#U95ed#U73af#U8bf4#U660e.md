# 双单位轮速 PI 闭环说明

## 1. 两种接口的定位

### count/s

```c
Chassis_SetWheelSpeedCps(3000, 3000);
```

优点：

- 直接对应编码器；
- PI参数分析最直接；
- 不受轮径标定误差影响；
- 适合底层调试。

缺点：

- 上层任务不直观；
- 更换轮径或编码器后，同一数值代表的真实速度变化。

### mm/s

```c
Chassis_SetWheelSpeedMmps(400, 400);
```

优点：

- 上层动作、距离规划和循迹速度更直观；
- 与赛题中的米、厘米和秒直接对应。

缺点：

- 依赖轮径和每圈计数参数准确。

因此本版本规定：

```text
App / Action / Chassis对外：优先mm/s
轮速PI内部：统一count/s
底层调试：可直接使用count/s
```

## 2. 单位换算

当前参数：

```text
每圈计数 = 1468
轮周长 = 204204 μm
```

换算：

```text
cps = mm/s × 1468 × 1000 / 204204
mm/s = cps × 204204 / 1468 / 1000
```

实现使用64位整数中间量并进行对称四舍五入，不使用浮点数。

示例：

```text
200 mm/s ≈ 1438 cps
400 mm/s ≈ 2876 cps
600 mm/s ≈ 4313 cps
```

## 3. PI结构

每个车轮都有独立控制器：

```text
目标count/s
  ↓
误差 = 目标 - 滤波实测
  ↓
P = Kp × 误差
I = I + Ki × 误差 × 实际周期/标称周期
  ↓
PWM = P + I
  ↓
限幅、抗饱和、方向保护
  ↓
TB6612
```

Q10参数：

```text
真实Kp = kp_q10 / 1024
真实Ki = ki_q10 / 1024
```

## 4. 为什么使用20 ms测速窗口

5 ms内一个编码器计数对应：

```text
1 count / 5 ms = 200 count/s
```

按当前轮径约等于：

```text
27.8 mm/s
```

直接用单个5 ms增量反馈，低速时会出现明显量化跳动。

本版本保存最近4个周期的：

```text
编码器增量总和
实际时间总和
```

计算：

```text
filtered_cps = sum(delta) × 1000 / sum(dt_ms)
```

PI仍然每5 ms更新，只是反馈速度更平稳。

## 5. 串口字段

闭环测试输出：

```text
LTG_MM/RTG_MM   左右目标mm/s
LM_MM/RM_MM     左右实测mm/s
LTG_CPS/RTG_CPS 左右目标count/s
LM_CPS/RM_CPS   滤波后实测count/s
LRAW/RRAW       当前5 ms原始count/s
LE/RE           左右速度误差count/s
LI/RI           积分项折算后的PWM
LP/RP           最终PWM
LD/RD           当前控制周期编码器增量
OVR             严重调度超时次数
```

## 6. PI整定顺序

### 第一步：只调P

把：

```c
WHEEL_SPEED_LEFT_KI_Q10
WHEEL_SPEED_RIGHT_KI_Q10
```

设为0。

逐步提高Kp：

```text
256 → 384 → 512 → 640 → 768 ...
```

目标是：

- 上升速度足够快；
- 没有持续振荡；
- PWM不频繁在0和高值之间跳变。

### 第二步：加入I

固定Kp，从较小Ki开始：

```text
2 → 4 → 8 → 12 → 16
```

目标是消除稳态误差。

如果出现慢周期上下摆动、明显过冲或积分项长期很大，Ki过大。

### 第三步：分别整定左右轮

左右开环特性存在约3%差异，允许左右参数不同，但不要先用固定PWM偏置代替闭环。

## 7. 安全边界

- 首次闭环必须架空车轮；
- PWM限制保持5000；
- 目标最大值保持700 mm/s或5032 cps；
- `OVR` 应始终为0；
- 发现编码器符号异常、速度突跳或单侧不转时立即断开电机电源；
- 架空测试稳定后再进行空旷地面短距离测试。
