# PI闭环V2设计与测试说明

## 控制结构

```text
目标速度
  ↓
左右轮开环前馈
  ↓
P比例修正
  ↓
I稳态修正
  ↓
PWM限幅与条件积分抗饱和
  ↓
TB6612
  ↓
电机与编码器反馈
```

计算形式：

```text
PWM = FF + P + I
```

当前参数：

```text
Kp_Q10：左右512
Ki_Q10：左右8
积分修正上限：±2500 PWM
总PWM上限：±5000
测速窗口：4 × 5 ms ≈ 20 ms
```

前馈：

```text
左：PWM ≈ 124 + 937/1024 × |target_cps|
右：PWM ≈ 183 + 954/1024 × |target_cps|
```

## 编码器异常保护

正常最高开环速度约5300 count/s，软件合理性上限设置为8000 count/s。

5 ms周期下：

```text
允许最大增量 = ceil(8000 × 5 / 1000) + 4 = 44 count
```

超过时：

- 拒绝该样本；
- 不加入底盘有效里程；
- 清除PI测速和积分状态；
- 两轮短路刹车一个控制周期；
- 增加REJ计数。

## 调试日志

```text
WSPDS：目标、实测、误差
WSPDP：前馈、P、I、最终PWM
WSPDX：增量、饱和、有效性、拒绝计数、超时、串口诊断
```

正常第一次架空测试应满足：

```text
V=1
REJ=0/0
OVR=0
DROP=0
TR=0
```

## 与UART4并行关系

UART4外设始终在main中初始化，但只有巡线测试或巡线模块调用 `BSP_LineUart_Init()` 后才开始查询通信。

在PI轮速测试模式下：

- USART1负责调试DMA发送；
- UART4不进入巡线查询状态机；
- TIM3/TIM4负责编码器；
- TIM9负责电机PWM。

两条链路没有资源冲突。
