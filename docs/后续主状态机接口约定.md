# 后续主状态机接口约定

本版本暂不实现正式主状态机，但菜单模块已固定以下接口：

```c
bool TaskMenuUi_TakeStartRequest(TaskMenuTask_t *task);
bool TaskMenuUi_TakeStopRequest(void);
void TaskMenuUi_SetFinished(void);
```

下一阶段的`MainApp_Update()`可以按以下方式接入：

```c
TaskMenuTask_t requested_task;

BSP_Key_Process();
TaskMenuUi_Process();
BSP_Oled_Process();

if (TaskMenuUi_TakeStartRequest(&requested_task))
{
    AppTask_Start(requested_task);
}

if (TaskMenuUi_TakeStopRequest())
{
    AppTask_Stop(APP_STOP_USER);
}

if (AppTask_IsFinished())
{
    TaskMenuUi_SetFinished();
}
```
