## 3. 编码器快照

正式闭环只调用：

```c
BspEncoderSample_t sample;
BSP_Encoder_Sample(&sample);
```

同一控制周期内，速度闭环、里程统计和日志使用同一份 `sample`。

旧接口仍保留给旧测试兼容：

```c
BSP_Encoder_GetLeftDelta();
BSP_Encoder_GetRightDelta();
```

但不得和快照接口混用于正式底盘控制。

## 4. 底盘接口

```c
bool Chassis_Init(void);
bool Chassis_Enable(bool enable);

bool Chassis_SetWheelSpeedMmps(
    int32_t left_mm_s,
    int32_t right_mm_s);

bool Chassis_SetVelocity(
    int32_t linear_mm_s,
    int32_t angular_mrad_s);

void Chassis_Stop(void);
bool Chassis_Update(void);
bool Chassis_GetStatus(ChassisStatus_t *status);
```

主循环持续调用 `Chassis_Update()`；内部每5 ms执行一次控制。

## 5. 测试顺序

### 第一步：开环阶梯测试

```c
#define PROJECT_TEST_MODE TEST_MODE_MOTOR_OPEN_LOOP
```

必须架空车轮。

PWM顺序：

```text
0, 500, 1000, 1500, ... , 5000, 0
```

每级保持2秒，每100 ms输出左右编码器速度。

记录：

- 左轮开始稳定连续转动的最小PWM
- 右轮开始稳定连续转动的最小PWM
- 相同PWM下左右速度差
- 编码器方向是否始终为正

然后填入：

```c
#define WHEEL_SPEED_LEFT_MIN_DRIVE_PWM  ...
#define WHEEL_SPEED_RIGHT_MIN_DRIVE_PWM ...
```

### 第二步：轮速闭环测试

```c
#define PROJECT_TEST_MODE TEST_MODE_WHEEL_SPEED
```

速度顺序：

```text
0 → 200 → 400 → 600 → 400 → 200 → 0 mm/s
```

每级保持3秒。

关键输出：

```text
LTG/RTG：左右目标mm/s
LM/RM：左右实测mm/s
LP/RP：左右PWM
OVR：控制周期严重超时次数
```

初始PI：

```text
Kp = 512 / 1024 = 0.5
Ki = 8 / 1024 = 0.0078125（每5ms）
```

整定建议：

- 响应太慢：先增加Kp
- 持续静差：增加Ki
- 明显振荡：降低Kp
- 来回缓慢摆动或积分过强：降低Ki

每次只修改一个参数。

### 第三步：直行同步测试

```c
#define PROJECT_TEST_MODE TEST_MODE_CHASSIS_STRAIGHT
```

程序以400 mm/s运行5秒，输出：

```text
LM/RM：左右实测速度
LP/RP：左右PWM
LT/RT：左右累计计数
DIFF：左累计计数-右累计计数
```

`DIFF`持续单方向增大，说明左右实际比例仍有系统差异，需要分别整定左右PI或检查轮径、机械阻力。

## 6. 5 ms控制周期说明

编码器每圈1468计数、轮径65 mm时：

```text
每计数约0.1391 mm
5 ms内1个计数约等于27.8 mm/s
```

因此低速瞬时速度会有量化跳变。判断PI效果时应同时观察多帧趋势，不要只看单个5 ms测量值。

## 7. 超时保护

本版本没有增加巡线ADC帧超时保护，遵从本轮范围。

底盘自身保留控制调度保护：

```text
正常：5 ms
超过25 ms未更新：本周期刹车、清PI、重新同步编码器
```

该保护用于避免调试断点或主循环卡顿后，按错误时间间隔继续输出大PWM。
