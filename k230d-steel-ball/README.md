# K230D 小钢球单类别识别

本目录提供正点原子 K230D BOX 上可直接部署的小钢球单类别 YOLOv8n 识别模型与
CanMV MicroPython 脚本。

## 基本信息

```text
开发板：正点原子 K230D BOX
摄像头：GC2093
固件：CanMV_K230D_ATK_DNK230D_micropython_v1.8-0-gc2d1f5c_nncase_v2.11.0
模型类别：steel_ball（单类别，class_id=0）
模型结构：YOLOv8n detect
量化方式：W8A16
模型输入：320x320
传感器视场：1280x960
AI 图像通道：320x240 RGB888P
置信度阈值：0.08
NMS IoU 阈值：0.45
```

交付文件：

| 文件 | 用途 |
|---|---|
| `steel_ball_yolov8n_320_nncase211_w8a16.kmodel` | K230D KPU 推理模型。 |
| `steel_ball_yolov8_v18.py` | 摄像头采集、推理、显示和文本输出主程序。 |
| `diagnose_steel_ball_kmodel_load.py` | 不启动摄像头，使用全零输入检查模型加载和 KPU 推理。 |

模型大小为 `3,494,192` 字节，SHA-256：

```text
3a89c2fc3a4b06faf003787784b7a9e7614baba5055179a6deec440266f9f0c0
```

## 当前识别策略

1. 显式以 `1280x960` 模式初始化 GC2093，保持与原始采集视场一致。
2. 使用独立的 `320x240 RGB888P` AI 通道，避免申请高分辨率 RGB888P 推理缓冲区。
3. AI2D 保持宽高比缩放，在上下填充到 `320x320` 后送入 YOLOv8n KModel。
4. 模型输出 `boxes [1,4,2100]` 和 `scores [1,1,2100]`，由板端执行 YOLOv8
   后处理和 NMS。
5. 去除 letterbox 产生的纵向偏移，将检测框映射回 `1280x960` 坐标。
6. 单类别程序只保留置信度最高的一个小钢球检测结果，同时绘制检测框和框中心。

当前模型已在 CanMV v1.8 / nncase 2.11.0 固件上完成独立 `kpu.run()` 与输出读取
验证。它可用于固定白底等简单背景；复杂背景召回率仍然偏低，尚不适合直接扩展到
未经验证的场景。

## 部署方法

1. 将 `steel_ball_yolov8n_320_nncase211_w8a16.kmodel` 复制到 SD 卡根目录：

   ```text
   /sdcard/steel_ball_yolov8n_320_nncase211_w8a16.kmodel
   ```

2. 首次部署先在 CanMV IDE 中运行 `diagnose_steel_ball_kmodel_load.py`，应依次看到：

   ```text
   stage=file_ok size=3494192
   stage=load_ok
   stage=run_ready
   stage=get_outputs_ready
   ```

   仅出现 `load_ok` 不能证明模型可以完成推理。

3. 运行 `steel_ball_yolov8_v18.py`。需要脱机自动启动时，可将确认无误的主程序复制
   为 SD 卡上的 `main.py`。
4. 在实际白底环境分别放入和移除钢球，确认 LCD 检测框和文本输出同步变化。

## 输出协议

检测到小钢球：

```text
SB,1,x1,y1,x2,y2,cx,cy,score_milli
```

未检测到小钢球：

```text
SB,0,0,0,0,0,0,0,0
```

| 字段 | 含义 |
|---|---|
| `SB` | 小钢球协议帧头。 |
| `1/0` | `1` 表示检测到，`0` 表示未检测到。 |
| `x1,y1` | `1280x960` 坐标系中的检测框左上角。 |
| `x2,y2` | `1280x960` 坐标系中的检测框右下角。 |
| `cx,cy` | 检测框中心，计算式为 `(x1+x2)//2, (y1+y2)//2`。 |
| `score_milli` | 模型置信度乘以 1000 后取整，例如 `180` 约等于 `0.180`。 |

`cx,cy` 是 YOLO 水平检测框中心，不是亚像素圆心，也不是实际空间坐标。

## 当前限制

- 当前部署阈值为 `0.08`，不能在未重新验证的情况下直接提高到 `0.20` 或 `0.25`，
  否则可能明显增加漏检。
- 小钢球在 `320x320` 模型输入中通常只有约 `15x15` 像素，对距离、反光、阴影、
  模糊和量化误差比较敏感。
- 当前模型主要面向固定白底等简单背景；复杂背景、强反光和远距离场景仍需优化。
- W16A16 候选虽然能加载，但在当前开发板上会停在首次 `kpu.run()`，因此正式部署
  使用已通过实机推理验证的 W8A16 模型。

## 后续优化

本交付目录暂不包含训练数据集。后续需要增加数据集和重新训练，以继续提高识别能力
和量化后的置信度，建议按以下步骤推进：

1. 使用正式安装位置、白底、实际照明和实际工作距离采集新的 `1280x960` 原图。
2. 覆盖不同距离、画面位置、反光、阴影、轻微模糊，以及无球和圆形反光等困难
   负样本。
3. 使用 YOLO HBB 格式逐图标注；没有钢球的图片保留同名空标签文件。
4. 按完整拍摄场景划分训练集、验证集和测试集，不能把相邻连拍图片随机分散到不同
   集合，以免验证数据泄漏。
5. 在“旧数据 + 新数据”的完整数据集上从 `yolov8n.pt` 重新训练；也可以使用当前
   `best.pt` 低学习率微调作为对照，但不能只训练新增照片。
6. 重新导出 `320x320` ONNX，并使用 nncase 2.11.0 转换 W8A16 KModel。量化校准图
   应覆盖实际距离、反光状态和负样本。
7. 使用未参与训练和量化校准的测试集比较 ONNX 与 KModel，统计有球检出率、无球
   误检率、检测框 IoU 和正负样本置信度间隔。
8. 最终候选必须在 K230D 上依次通过独立 KPU 推理、实时摄像头识别和连续运行验证。

建议的固定白底验收目标：有球检出率不低于 `95%`，无球及困难负样本误检率不高于
`1%`，并保证最低正样本分数与最高负样本分数之间存在稳定阈值空间。
